# Getting started on ION

## Introduction

This document gives a bird eye's view on how to get started and have your app working on ION. The document is intended to be short and will link to other documents for detailed steps.

**Step 1: Signup your organization on ION Central**
- Get login credentials. 
- Start submitting KYC documents at your convenience (Need to finish before going to production)
- Reference: 
  - ION Central signup guide

**Step 2: Understand usecases related to your business by going through specs and trying on your laptop**
- Read the specs related to your business usecases to understand the protocol used to communicate with counter party.
- Bring up an entire network on your laptop and see the messages in action in a mock environment.
- Reference: 
  - How to use the ion-specs repository
  - Using the devlabs to explore Usecases and API
  - Using docker compose to understand use cases

**Step 3: Develop your app while interacting with other apps in a live sandbox network**
- Get Beckn credentials for sandbox network.
- Download ION-ONIX and configure it
- Develop application incrementally while trying functionality with the network.
- Reference:
  - Developing application with Docker Compose network
  - Developing application with ION Sandbox

**Step 4: Once your app is ready, check production readiness**
- Test your application with validation test suite
- Reference:
  - How to use the validation test suite

**Step 5: Get into ION Production Network and transact**
- Get access to production keys and start transacting on live network.
- Reference:
  - Getting started on the ION Production network
